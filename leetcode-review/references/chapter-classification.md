# 章节判定规则

先把每道已解决题目归入一个主章节，再参与抽题。章节由用户当前课程定义，不等同于题目拥有哪些标签；同一道题有多个标签时，以解题所需的核心方法为准。

## 前五章

### 数组

典型主方法包括下标访问、双指针、滑动窗口、前缀和、二分查找、原地修改，以及用哈希表记录数组元素。矩阵题只有在核心操作仍是数组/矩阵遍历或索引处理时归入本章。

### 链表

题目主体操作是单向链表、双向链表、环形链表、合并、反转、快慢指针、删除或重排节点时归入本章。仅为表示输入而复用链表、主算法属于其他章节的题，不作为链表候选。

### 栈

核心依赖后进先出、括号匹配、表达式求值、嵌套结构、单调栈或栈式模拟时归入本章。图中的 DFS 即使内部使用栈，也仍属于图论搜索，不能放入本章。

### 二叉树

核心是二叉树的遍历、递归、分治、深度/高度、路径约束、二叉搜索树性质或树的序列化时归入本章。普通多叉树、图结构或堆题不要仅因“树”字面相近而放入。

### 回溯算法

题目需要显式进行选择、递归探索和撤销选择，典型包括排列、组合、子集、切割、棋盘放置和满足约束的路径枚举。如果只是一次递归遍历且没有候选选择与撤销过程，优先归入二叉树或其他章节。

## 暂不出的章节

### 图论搜索

包括图的 BFS/DFS、网格连通块、拓扑排序、并查集、最短路径和图的建模。即使页面标签还有“队列”或“栈”，只要主问题是图搜索，就不出。

### 动态规划

包括一维/多维 DP、背包、区间 DP、序列 DP、状态压缩、记忆化搜索等。即使题目同时带“数组”标签，只要核心是 DP，就不出。

## 冲突与缺省

- 先排除图论搜索和动态规划，再检查前五章。
- 一道题只分配一个主章节；不要为了让某个章节有题而重复使用同一题。
- 若标签、标题和题意互相冲突，打开题目确认核心方法。
- 若仍然无法可靠分类，宁可放弃该候选，也不要猜。
- 用户明确说某章已经开始学习之前，始终排除最后两章。
